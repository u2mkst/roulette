# KST Roulette

A customized fork of the original marble roulette project.

## Features
- Original roulette visual style
- Ads managed from `/admin.html` (Supabase)

## Development
```sh
yarn install
yarn dev
```

## Map testing
```sh
yarn probe all 30 1,2,3   # physics-only check: stuck marbles, obstacle usage, fork balance
```

## Build
```sh
yarn build
```
