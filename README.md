# KST Roulette

A customized fork of the original marble roulette project.

## Features
- Original roulette visual style
- Clear result display
- Fullscreen mode
- Add and remove roulette entries

## Development
```sh
yarn install
yarn dev
```

## Build
```sh
yarn build
```
